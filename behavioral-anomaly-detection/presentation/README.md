# Presentation

The problem statement requires submitting a presentation using the
organizers' provided template ("Use this template with relevant slides
filled in"). That template wasn't attached to the problem statement doc
included in this project — drop the actual `.pptx`/`.potx` template file
here once you have it and fill in slides using the content already drafted
in `reports/report.md` (section headers map roughly 1:1 to typical
hackathon slide structure: problem → approach → data → results →
demo/dashboard → limitations → next steps).

If you'd like, ask for the deck to be generated once the template file is
available and the report has real numbers in it.
